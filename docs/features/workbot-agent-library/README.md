# Workbot: My agent in the Library

Feature `workbotAgentLibrary` (cloud and self-hosted, off by default). Author: `benjaminshafii`.
It needs `workbotProactive` ("Your agent", see [its doc](../workbot-proactive/README.md)) on for the member.

Members can see what their agent did, why it stayed quiet, and tell it what they care about in their own words.
Chat is the main way to change it; the Library page shows the same state and has an Undo next to every change.

Work in progress: the rest of this doc lands with the feature.
